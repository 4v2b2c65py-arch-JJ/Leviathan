# Leviathan

Game-intended data/model creation workspace: game landing page, asset replication, AGI NPC system, crypto compute server keeper, and Unity material base.

## Structure
- `games/landing-page/` — Next.js 15 game landing portal (Vercel-deployable)
- `games/asset_replication/` — Turbosquid/Vket/Kimi/Hugging Face asset replication for Unity
- `games/npc_agi/` — Autonomous AGI NPCs (think, sleep, interact, offline-persist)
- `games/crypto_compute/` — User-base compute earning LEVI crypto for server uptime
- `games/server_keeper/` — Heartbeat + auto-restart server keeper
- `games/image_reference/` — Face schematics & body polygons from image/Google generation
- `games/materials/` — Unity PBR material base (Built-in + URP shaders)
